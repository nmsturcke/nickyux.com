Sentry → GitHub

From an error alert to an issue your team can act on.

My role

Creator & developer

Focus

Self-hosted developer tooling

Keep errors close to the code.

The workflow.

Sentry-To-GitHub is a self-hosted Python service that turns Sentry alerts into GitHub issues, helping developers track errors alongside their code.

The implementation.

The service is built with Quart and MongoDB and uses GitHub App authentication. Repositories, labels, and assignees are configurable to fit a team’s workflow.

What it demonstrates.

This project connects API integration and developer tooling with an operational concern: getting error reports into the place where a team can act on them.

Explore the source.

The public repository includes the implementation and setup instructions.
