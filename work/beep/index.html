Beep

A Discord economy with multiplayer games and a real-time foundation.

Repository being prepared for release
My roleCreator & developer
FocusDiscord economy & games platform

The platform.

Beep combines a virtual economy with interactive multiplayer games in a Discord application. Its backend coordinates the Discord bot and activity frontend.

Connected in real time.

I developed a Python backend using Quart, asynchronous HTTP APIs, and WebSockets. MongoDB stores users, communities, balances, and game data.

Authentication & visibility.

I integrated Discord OAuth2 authentication and monitoring through Prometheus, Grafana Loki, Tempo, and Sentry.

Opening the source.

I’m preparing the repository for public release. A source link will be added here once it’s available.
